Vectors and matrices are the fundamental language of modern AI. A **vector** is simply an ordered list of numbers — for example, [0.2, 0.8, −0.5] — which can represent anything from a word's meaning to a pixel's color to a user's preferences. In neural networks, data is constantly being expressed as vectors so that math can be applied to it. You can think of a vector as a point (or arrow) in multi-dimensional space: the more dimensions, the richer the information it can encode. This is why you'll often hear about "embeddings" in LLMs — a word or sentence gets compressed into a high-dimensional vector that captures its semantic meaning.

**Matrix multiplication** is the core operation that transforms these vectors as they flow through a neural network. A matrix is a 2D grid of numbers, and multiplying a matrix by a vector produces a new vector — essentially rotating, scaling, and mixing the original values together. Each layer of a neural network is largely just a matrix of learned weights doing this transformation: it takes an input vector, matrix-multiplies it, and outputs a new vector for the next layer to process. What makes this powerful is that the network *learns* the right weight values during training, so over millions of examples it discovers which matrix transformations best solve the task at hand. In LLMs specifically, enormous matrices (with billions of parameters) are what allow the model to encode grammar, facts, reasoning patterns, and even tone — all expressed as sequences of vector transformations.

For a concrete example, imagine multiplying a 2×2 matrix by a 2-element vector: you take each row of the matrix, multiply its elements by the corresponding vector elements, and sum them up to produce each element of the output vector:

$$\begin{bmatrix} 2 & 0 \\ 1 & 3 \end{bmatrix} \begin{bmatrix} 4 \\ 5 \end{bmatrix} = \begin{bmatrix} (2×4)+(0×5) \\ (1×4)+(3×5) \end{bmatrix} = \begin{bmatrix} 8 \\ 19 \end{bmatrix}$$

In a neural network, the matrix holds the learned weights and the input vector holds the data — so this one simple operation is how a neuron "processes" its inputs into a new representation.
